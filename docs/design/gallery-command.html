Loc8 Command · control room

Mission control for the night shift

The supervisor's dashboard for security ops — live team map, incident feed, muster headcount and coverage — running on the same offline mesh as every guard's phone. Five views of one control room, network-independent by design.

— build note · pattern learned in apps/command —
The “ANONYMISED” tag on view 05 needs a home for the exception. Building the console surfaced a sixth dashboard — “Assisted search & audit” — as the concrete backing for the privacy model. The heatmap proves counts-only monitoring; the audit view proves the only path from anonymous crowd to a named individual is narrow and accountable: it is reason-gated (a search refuses to run without a logged justification), searches only consent-carrying subjects (on-duty staff, SOS initiators, opt-in medical, family crews), and writes an audit entry for every attempt. There is deliberately no data structure holding attendee identities — the crowd exists only as per-zone counts, so a browsable live map of people cannot be built. Recommend adding this as view 06 in a future revision of this gallery. (Implemented in apps/command; see src/domain/privacy.ts.)
