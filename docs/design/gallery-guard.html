Loc8 Guard · field team

The phone in every guard's pocket

A tactical, offline-first app for security and field staff — live team map, one-hold SOS, nearest-responder dispatch, lone-worker check-ins, incident logging and muster. It keeps working when the network is jammed or dead, over the same offline mesh as the consumer app.

◈ SHIPPED — apps/guard on @loc8/engine (2026-07-08). Patterns the build refined:
• Hold-to-confirm everywhere — every serious/irreversible action is press-and-hold with a live progress fill, never a bare tap, so nothing fires by accident: SOS (raised nav slot, 1s, a red ring sweeps the circular outline → haptics.sos()), Declare muster (2.5s), and stand-down / I'm-OK on the SOS screen (rectangular buttons fill left→right via the shared HoldButton). Release early and the fill drains back. I'M SAFE stays an instant tap on purpose — in an evacuation, checking in must be fast. SOS is reachable from any tab.
• SOS & incidents ARE the engine rally pin — an SOS drops your position as the shared converge target (meshService.dropRally()) plus a free-text alert; responders navigate to that pin. One active pin at a time.
• Status responses reuse the quick-reply mechanism — additive ops codes En route / On scene / Need backup / Clear sent with sendQuickReply(); team comms + incident/muster alerts use the engine's free-text fragmentation.
• Live map — blips are projected from real crewStore positions (geoMath bearing/distance), not fixed dots.
• Floors / levels — venues are 3D. Every position carries a floor (bit-packed into the heading field, so zero extra bytes on the 25-byte frame), detected automatically by the barometer (self-baseline at clock-in + hysteresis; floorService) with a manual pin as override. The map has a floor switcher (peek any level, per-floor head-counts); incidents/SOS are floor-tagged and dispatch shows ▲up / ▼down; muster counts per floor; the roster shows each guard's level. Barometer is device-only — sim/web fall back to manual. This lives in @loc8/engine so Consumer/Command inherit it.
