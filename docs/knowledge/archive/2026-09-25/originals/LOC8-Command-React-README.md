# LOC8 Command

A new **React + TypeScript** desktop/tablet application, with an actual **PixiJS operational map** and a matte-black control-room interface.

This is a **functional local exercise application**, not a live safety system or a replacement for the existing `EmotiveImpact/loc8` engine. It is a separate local repository. No GitHub remote is configured and nothing has been pushed.

## Start here

```bash
npm install
npm run dev
```

Open `http://localhost:5182` on your computer. Node.js 22.12 or newer is required. The first installation needs an internet connection.

**Build status:** this delivery environment could not reach the npm registry. Consequently, the dependency-resolved Vite build, pinned Pixi runtime and native installers have **not been verified**. There is no fabricated lockfile or binary. The pure domain tests and a constrained React/SVG review were executed successfully. Read [TESTING.md](docs/TESTING.md) before treating this as a validated release.

After the first successful installation, commit `package-lock.json`. Then use `npm ci` for repeatable dependency installation and CI.

### Production web build

```bash
npm run build
npm run serve
```

`dist/` is generated by Vite. A post-build script adds an app-shell service worker using content-derived cache versions. It does not cache workspace JSON or camera streams.

### Desktop

Install Rust and the Tauri prerequisites for your operating system, then:

```bash
npm run desktop:dev
npm run desktop:build
```

The Tauri 2 project lives in `src-tauri/`. It includes a native, user-selected JSON save dialog and a tightly scoped application command, rather than a general-purpose filesystem API. Native builds, WebView compatibility, signing and notarisation still need verification. No `.app`, `.dmg`, `.exe` or AppImage is included in this delivery.

### Tablet

The tablet target is the **same responsive React web app**, not an Expo Go application.

Deploy `dist/` to an HTTPS static host, open it on the tablet and use the browser's installation / Add to Home Screen action where supported. It needs an initial successful online load before offline use. For layout review on a trusted local network, Vite listens on `0.0.0.0`, so the tablet can open `http://YOUR-COMPUTER-LAN-IP:5182`. Ordinary LAN HTTP is not a production PWA installation route.

For Command, React DOM + PixiJS + Tauri/PWA avoids maintaining a second native UI. Guard and the consumer mobile application can retain their existing Expo architecture. This repository does not modify either of them.

## Implemented

| Area | Actual implementation |
| --- | --- |
| React interface | Functional components, typed actions, external-store subscriptions, modal forms, keyboard search and error boundary. It does not mount the previous HTML prototype. |
| Map | Actual PixiJS v8 scene code, illustration/vector plan, staff/incident/gateway markers, uncertainty rings, floor filtering, layer controls, mouse pan, wheel zoom, touch pan/pinch and fit. |
| Renderer fallback | If Pixi or WebGL cannot initialise, an explicitly labelled interactive SVG plan remains available. It is never labelled as WebGL. |
| Incident desk | Create, inspect, acknowledge locally, note, dispatch and resolve with a reason. The action bar stays outside the scrollable incident detail. |
| Dispatch | Separate local queue and explicit simulated receipt. No automatic acknowledgement; a queued task does not mark the responder en route. |
| Team | Authorised on-duty staff, observation age, fresh/stale/missing distinctions, revocation and restoration. Revocation removes the position and cancels queued tasks. |
| Network | Four simulated gateways, link pause/resume, task review, explicit simulated receipt and on-scene status. |
| Muster | Snapshot roster, manual per-person check-in, stand-down reason and outstanding count. No position-based safe assumption or evacuation broadcast. |
| Cameras and glasses | Separate media components, local image/video preview, play/pause/end state, fullscreen, removable source and independent glasses HUD. Initial images are labelled illustrative stills. |
| Persistence | Native IndexedDB module, queued saves, checked imports, JSON export and a visible failure state. Restored/imported workspaces always start with the feed paused. |
| Tablet layout | Compact navigation, incident drawer, touch controls, responsive tables and reduced-motion/high-contrast/low-power settings. |
| PWA | Manifest, icons, local app-shell cache generation, explicit update prompt rather than forced reload. |
| Desktop shell | Tauri project, local-window capability file, CSP, native export command and manual unsigned-build workflow. Not compiled here. |

The source includes **no Rive, Three.js or Babylon.js dependency**. There is no authored Rive asset or 3D building in this version, so those engines would add weight without implementing a useful feature. The map uses PixiJS; panels and forms remain ordinary React/HTML/CSS.

## Exercise walkthrough

1. Select `INC-042` and acknowledge it locally.
2. Dispatch an available responder such as `M-04`. The task is **queued**, not received.
3. Open **Network** and use **Simulate receipt**, then **Simulate on scene**.
4. Pause the exercise link. The stored observations stop changing while their age increases.
5. Open **Team** and revoke a staff member's visibility. Their map position is removed.
6. Start a **Muster** drill and check in staff manually.
7. Open **Glasses**, load a local image/video and switch the HUD independently.
8. Export the exercise checkpoint. Importing it resumes neither a link nor fresh positions automatically.

Search: `Ctrl/Cmd + K`. Navigation shortcuts: `Alt + 1` map, `Alt + 2` incidents, `Alt + 3` team, `Alt + 4` network. `Escape` closes dialogs.

## Validation

```bash
npm test
npm run typecheck
npm run build
# In another terminal with the dev server running and Python Playwright installed:
npm run test:browser
```

Executed here: **45 pure-model tests**, **48 constrained React interaction/layout checks**, and a syntax pass across all 22 TypeScript/TSX source modules. The browser harness used an already installed React 19.1.1 runtime and the SVG fallback because this environment blocked npm downloads and browser navigation. IndexedDB was unavailable in that harness and its failure was displayed rather than hidden.

These results do **not** certify React 19.2.3 + Pixi 8.20.1 dependency integration, WebGL output, real persistence, the PWA lifecycle or native Tauri behaviour. Those are the next checks on a normal development machine.

## Boundaries

Fictional venue, staff and observations. No live BLE, measured indoor positioning, real radio dispatch, multi-user access control, encrypted production audit store, actual camera/glasses transport, threat recognition or military certification is present. Routes and floor geometry are illustrative and must not be used for navigation. No all-attendee map is implemented.

This is not an emergency response system. Production credentials and hardware must not be pointed at the exercise simulator.
