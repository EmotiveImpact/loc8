# R&D results

Create one directory per result:

```text
<question-id>/<yyyy-mm-dd>-<short-name>/
```

Copy [`../templates/result-template.md`](../templates/result-template.md) into
that directory as `README.md`. Store small, non-sensitive reproducible analysis
and redacted evidence with it. Large or sensitive raw data may remain outside Git,
but its durable location, access rules and cryptographic hash must be recorded.

Do not store identifiable staff/member-of-public location trails here without an
approved collection, consent/access and retention protocol.

An empty or failed result is still a result. Publish it and make a decision.
